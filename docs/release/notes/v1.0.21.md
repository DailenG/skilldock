## 新增

- Pi 和 OMP 插件可以安装、列出，并按 Skill、MCP、Hook 分别识别。
- 同一 Git 仓库安装到多个宿主时合并为一张卡片，来源显示 Git 仓库地址。
- 启用和停用会写入 Pi、OMP 的 `settings.json`，宿主重新启动后生效。

## 修复

- 修复 OpenCode npm 插件（例如 oh-my-opencode-slim）因仓库克隆失败而无法安装的问题。
- 修复中文名全局 Skill 删除失败的问题，改为直接删除原目录和锁记录。
- 修复 Pi、OMP 插件目录已删除后仍留在列表中的问题。
- 安装完成后界面不再长时间停在「正在完成安装」。
